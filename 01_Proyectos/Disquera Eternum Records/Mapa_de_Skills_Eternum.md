# Mapa de Skills Eternum

## Capas del sistema

### 1. Direccion sonora
Usar para decidir el camino musical antes de escribir.

- `eternum-ar`

### 2. Letras
Usar para escribir o mejorar versos, estructura y respiracion vocal.

- `eternum-lyrics`

### 3. Hooks
Usar para crear coros, ganchos y frases memorables.

- `eternum-hooklab`

### 4. Produccion
Usar para definir arreglo, capas, transiciones y dinamica.

- `eternum-production`

### 5. Prompt final
Usar para convertir todo en un paquete listo para Suno.

- `eternum-suno`

### 6. Visuales
Usar para portada, estetica, color y lenguaje visual.

- `eternum-visuals`

### 7. Release
Usar para catalogo, versiones, metadatos y publicacion.

- `eternum-release`

### 8. Growth
Usar para contenido corto, captions y promocion.

- `eternum-growth`

### 9. Rights
Usar para creditos, splits y propiedad.

- `eternum-rights`

## Flujo recomendado

1. Definir direccion sonora.
2. Construir hook.
3. Escribir letra.
4. Diseñar produccion con energia por seccion.
5. Cerrar prompt de Suno con cues y secciones.
6. Crear visual.
7. Registrar lanzamiento.
8. Activar growth.
9. Cerrar derechos.

## Estandar Suno

- Intro energy
- Verse energy
- Chorus energy
- Bridge break
- Outro decay
- Instrumental cues

## Regla

- Un cue fuerte por cancion ya funciona si esta bien puesto.
- El cambio de ritmo debe verse en la seccion, no escondido en la letra.
- Si la base compite con la voz, vuelve a simplificar.
- Si el hook no funciona, corrige antes de seguir.
- Si el lanzamiento no esta claro, no se publica.
