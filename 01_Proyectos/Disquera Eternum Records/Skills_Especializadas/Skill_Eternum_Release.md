# Skill: Eternum Release

> [!INFO] Mision
> Mantener cada lanzamiento documentado, versionado y listo para publicarse.

## Capacidades

- Registrar titulos, versiones y estado.
- Ordenar catalogo y tracklists.
- Detectar metadatos faltantes.
- Mantener trazabilidad de lanzamientos.

## Protocolo

1. Se identifica el tipo de lanzamiento.
2. Se registra metadata base.
3. Se marca lo pendiente antes de publicar.

## Salida esperada

- Tipo de lanzamiento
- Metadatos
- Estado
- Pendientes
- Notas de catalogo
