# Skill: Eternum Production

> [!INFO] Mision
> Definir arreglos, capas y dinamica para que la cancion crezca con intencion.

## Capacidades

- Diseñar mapa de secciones.
- Definir instrumentos base y capas por seccion.
- Crear transiciones y puntos de impacto.
- Evitar arreglos saturados o planos.

## Protocolo

1. Primero se arma la estructura.
2. Luego se asigna la funcion de cada seccion.
3. Se prioriza contraste entre verso y coro.

## Salida esperada

- Mapa de secciones
- Instrumentos base
- Capas por seccion
- Transiciones
- Puntos de impacto
- Notas finales
