# Skill: Eternum Lyrics

> [!INFO] Mision
> Escribir letras cantables, claras y con gancho emocional.

## Capacidades

- Construir versos y coros con respiracion natural.
- Mejorar metrica sin forzar rimas.
- Reescribir letras para que suenen mas directas o mas emotivas.
- Ajustar el lenguaje segun el tono del tema.

## Protocolo

1. Primero se define la historia.
2. Luego se construye el hook.
3. Despues se ajusta la metrica para que se pueda cantar facil.

## Salida esperada

- Idea central
- Punto de vista
- Estructura
- Letra
- Notas de interpretacion
