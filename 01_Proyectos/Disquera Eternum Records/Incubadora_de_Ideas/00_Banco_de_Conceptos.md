# Banco de Conceptos

## Uso

Este archivo guarda semillas, no canciones cerradas.

## Como trabajar aqui

1. Capturar ideas rapido.
2. Marcar si la idea es para single, EP o album.
3. Definir una sola frase de identidad.
4. Pasar la idea a `eternum-ar`, `eternum-hooklab` o `eternum-lyrics` cuando toque desarrollarla.

## Plantilla minima

- Titulo provisional
- Tipo de proyecto
- Vibe
- Tema central
- Posible direccion sonora
- Riesgo o gancho principal

## Ideas activas

### EP ADN
- Tipo de proyecto: EP
- Vibe: identidad, origen, legado
- Tema central: construir personalidad artistica
- Posible direccion sonora: corrido moderno sobrio con tension emocional
- Riesgo o gancho principal: sonar demasiado generico si no se define una imagen fuerte

### EP Corridos Panamenos
- Tipo de proyecto: EP
- Vibe: calle, identidad local, fusion regional
- Tema central: mirar Panam a traves de Eternum
- Posible direccion sonora: corrido moderno con elementos urbanos discretos
- Riesgo o gancho principal: perder autenticidad si la fusion no tiene proposito

## Regla

- Si una idea ya tiene direccion clara, se mueve a desarrollo.
- Si una idea no tiene gancho, se sigue afinando aqui.
